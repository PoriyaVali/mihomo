# Mihomo v1.19.32-dm5

Includes all changes merged after v1.19.32-dm4:

- Correct HTTP keep-alive authentication and preserve the verified identity for requests without new credentials (PR #6).
- Update Mieru and ShadowQUIC users without restarting their listeners; give each Mieru UDP association its own source address (PR #7).
- Add managed multi-user Sudoku and Snell listeners, live user updates and correct source addresses for Sudoku HTTP tunnels and multiplexed streams (PR #8).

Ten binaries cover the existing Android, Windows, Linux and OpenWRT targets; SHA256SUMS is included. These are core binaries, not a Doctor Mobile app update.

Implementation: Claude's merged commits. Existing Android and managed-server checks completed successfully before this release. Tests were not rerun, at the owner's request; release builds and asset completeness were checked separately.

Compatible managed Sudoku and Snell nodes are included in [V2bX v1.11.0](https://github.com/PoriyaVali/V2bX/releases/tag/v1.11.0).
